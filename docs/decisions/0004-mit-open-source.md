# 0004. Open source under MIT

- **Date:** 2026-11-08
- **Status:** Accepted

## Context

A public directory of agents only works if businesses and developers trust it won't be locked down later. It is also a portfolio project that should be easy to read, fork and reuse.

## Decision

Publish the code under the MIT license with a contribution guide, code of conduct and security policy.

## Alternatives considered

- **Apache 2.0:** adds an explicit patent grant. Worth revisiting if larger companies start contributing.
- **AGPL:** stops closed hosted forks, but scares off many contributors and businesses.
- **Closed source:** fights the commons idea the product depends on.

## Consequences

Anyone can build a closed product on this code. The defensible value is the live directory, its listings and its reputation data, not the code.
