# Audit: end of Phase 1

- **Date:** 2026-11-08
- **Scope:** branch `phase-1-agent-line` (Phase 0 and Phase 1)
- **Method:** I ran five independent expert reviews in parallel: QA engineering, application security, software architecture, DevOps/CI, and product plus portfolio. Each reviewer worked read-only and was given the code, not my opinions. I then reproduced the top findings myself before accepting them.

**Headline:** the build, lint and 11 tests all pass, and CI should go green on first push. But the tests are thin. Five real bugs got past them, and two of them sit directly on the path of Phase 2's approval gate. Several docs also describe things as done that are still planned.

### Before production

No auth or rate limits on the barber agent. Express error pages leak stack traces and file paths. The client trusts the card's advertised URL and follows redirects (an SSRF risk once a hosted service reads URLs from the directory). Package `exports` point at `.ts` source, which only works because pnpm symlinks resolve outside `node_modules`. Run `pnpm audit` in CI.

## Documentation accuracy

The docs claim some things the repo doesn't back up yet:

- "CI blocks it from `main`" and "every merged change has a review on record". No remote exists yet, and `main` was built from direct commits.
- README says the agents "agree on a slot". They don't: the barber only offers. Approve, confirm and calendar are Phase 2 and later.
- MCP and the directory, gate and ratings are written in the present tense. They're planned.
- The journey says the first bug was "caught before it ran anywhere", but the bug log says it crashed on load.
- The test breakdown lists 9 of the 11 tests.
- "Shuts the door on prompt injection" should be "narrows": free-text fields remain (finding 3 and 4).
- ADR 0007's "every decision is logged" isn't true until Phase 2.

## Product and business

The product review challenged the brief on five points. I'm taking them into the next revision of [insights.md](../insights.md):

1. **The approval gate is the trust floor, not the moat.** Other agent products already confirm before acting. What's different here is a gate between _two parties'_ agents, logged for both sides. The moat is the directory plus reputation from verified interactions.
2. **Booking platforms are the real competition for barbers** (Booksy, Square, Fresha and others). They own the calendar and could ship an A2A endpoint themselves. ADR 0008 has to answer that.
3. **Cold start is hardest on the consumer side.** Almost nobody's assistant speaks A2A yet, so the built-in agent in the Phase 4 app has to be the consumer agent at launch.
4. **The market claims need sources and a date.** "Nothing does X" claims must name what I checked.
5. **The north star needs a time window and a quality guard:** weekly human-approved bookings that were honored, plus a baseline time-to-book measured before building more.

**The three riskiest assumptions, and how to test each without code:**

| Assumption                                                                                 | Cheapest test                                                                                                                    |
| ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| People will book through an agent and approve offers, instead of tapping an app or calling | Two-week Wizard-of-Oz test over WhatsApp with about 15 people. Measure repeat bookings and time-to-book against their usual way. |
| Barbers will list, and their booking tool allows programmatic booking                      | Interview 10 local barbers, desk-audit which booking tools have write APIs, and put up a one-page signup.                        |
| A neutral directory is defensible and someone pays for it                                  | A dated competitor scan, plus a pricing question in the barber interviews.                                                       |
