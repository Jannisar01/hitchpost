# Security policy

Hitchpost lets agents act for people, so security reports are taken seriously.

## Reporting a vulnerability

**Please don't open a public issue.** Use GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**.

Include what you found, how to reproduce it and the impact you expect. You'll get an acknowledgement within 72 hours and a plan for a fix after triage.

## Especially in scope

- Prompt injection that makes an agent act without human approval.
- Impersonating a business or person in the directory.
- Leaking calendar, contact or booking data between agents.
- Bypassing rate limits or the approval gate.

## Supported versions

The project is pre-release. Only the latest `main` is supported.
